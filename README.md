# Pokemon Stats
A website where you can search for a Pokémon's name and it returns some data such as an image of the Pokémon, its weight, and height.

## Why did I do this?
I created this website to further understand how APIs work here; I had to learn how to use them and how to collect the data to display to the user!

## Which API did I use?
The API used was `https://pokeapi.co/`, more specifically as: "https://pokeapi.co/api/v2/pokemon/pikachu". My code simply takes the name of the Pokémon you typed and checks if it exists; if it does, it displays some information on your screen.

## Other things I did on this project:

- The website's background bars are calculated using JavaScript. It performs calculations based on your screen width to determine how many bars to add for a visually appealing design.
